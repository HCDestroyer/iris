# Manual de Iris

Iris es el sistema de atención y trabajo de campo del ISP: tickets de soporte, órdenes de trabajo, agenda de técnicos, conversaciones de WhatsApp y seguimiento comercial. Este manual explica cada pantalla en palabras sencillas: para qué sirve, cómo se usa, qué significa cada estado y qué permiso hace falta.

Cada pantalla de Iris tiene un botón **?** que abre su página de este manual. También puedes buscar arriba.
