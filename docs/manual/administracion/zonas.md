# Zonas

## Para qué sirve

Las zonas dividen el territorio donde trabaja la empresa. Se usan en tickets, órdenes, cuadrillas, agenda y permisos por zona.

## Cómo se usa

1. En **Administración**, abre **Zonas**.
2. Con Argos conectado, sus zonas llegan solas y no se renombran en Iris.
3. Sin conector, pulsa **Nueva zona**, escribe el nombre y pulsa **Crear zona**.
4. Para cambiar el nombre de una zona local, ábrela y edítala.
5. Activa o desactiva las que hagan falta.

## Qué significa cada estado

- **De Argos:** viene del catálogo de Argos.
- **Activa** o **Inactiva:** una zona inactiva no se puede usar en tickets ni órdenes nuevos.

## Preguntas frecuentes

**No puedo renombrar una zona.**
Es de Argos: cámbiala allá.

## Permisos necesarios

- `agenda.crear_zona`, `agenda.editar_zona`, `agenda.activar_zona` y `agenda.desactivar_zona`, con alcance global (**Supervisor**).
