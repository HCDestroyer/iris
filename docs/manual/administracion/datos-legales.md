# Datos legales

## Para qué sirve

Llenar quién opera el servicio y cómo contactarlo. Con estos datos Iris arma las páginas públicas de privacidad, términos y eliminación de datos que pide Meta para WhatsApp.

## Cómo se usa

1. En **Administración**, abre **Datos legales**.
2. Escribe la **Razón social** y el **Nombre comercial** (el mismo que usas en Meta).
3. Escribe el **Contacto de privacidad**: correo y, si quieres, teléfono.
4. Escribe la **Dirección** y el **País**.
5. Guarda. Copia los enlaces de las páginas y pégalos en Meta.

## Qué significa cada estado

- **Datos completos:** las páginas públicas están listas para Meta.
- **Faltan datos legales:** las páginas se abren, pero no dicen quién es el responsable.
- **Responde bien**, **Responde, pero faltan datos** o **No responde:** el estado de cada página pública.

## Preguntas frecuentes

**Una página no responde.**
Avisa a quien administra el servidor de Iris.

## Permisos necesarios

- Ver: `datos_legales.ver`. Cambiar: `datos_legales.configurar` (**Administrador**).
