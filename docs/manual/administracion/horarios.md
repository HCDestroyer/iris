# Horarios

## Para qué sirve

Definir en qué horas atiende cada número de WhatsApp y cada cola, con sus feriados. Fuera de horario el plazo de respuesta no corre y el número puede contestar solo.

## Cómo se usa

1. En **Administración**, abre **Horarios**.
2. Pulsa **Nuevo horario** o abre uno.
3. Escribe el nombre y elige la **Zona horaria**.
4. Agrega las franjas de cada día. Si cruza la medianoche (22:00 a 06:00), escríbela como dos franjas.
5. Si usas perfiles del asistente, elige el perfil de cada franja.
6. Agrega los feriados. Marca **Cerrado todo el día** si ese día no se atiende; si no, sus franjas reemplazan las de ese día.
7. Pulsa **Crear horario** o **Guardar cambios**.
8. Elige el horario en la configuración de cada número o cola.

## Qué significa cada estado

- **Sin horario:** el número o la cola atiende siempre.
- **Sin franjas:** el horario queda siempre cerrado.
- **Sin feriados:** no tiene días especiales.

## Preguntas frecuentes

**Dice «Una franja usa un perfil del asistente que ya no existe».**
Elige otro perfil en esa franja y guarda de nuevo.

## Permisos necesarios

- `canales.configurar` (**Supervisor**).
