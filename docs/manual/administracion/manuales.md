# Biblioteca de manuales

## Para qué sirve

Guardar guías para el equipo y para enviar al cliente desde la bandeja de conversaciones: reiniciar el módem, revisar la potencia, configurar el wifi… No confundir con este manual de Iris.

## Cómo se usa

1. En **Administración**, abre **Biblioteca de manuales**.
2. Busca por palabra o modelo del equipo.
3. Pulsa **Nuevo manual**.
4. Escribe el **Título** (se ve en las sugerencias de la bandeja) y el **Contenido**. Revisa la **Vista previa**.
5. En **Para encontrarlo**, pon palabras separadas por coma y, si aplica, el **Equipo** (modelo).
6. En **Quién lo ve**, elige **Del equipo** (solo agentes) o **Para el cliente** (se puede enviar como enlace o texto).
7. Pulsa **Crear manual**.
8. Si tu biblioteca está vacía, usa **Cargar manuales de inicio**: trae ejemplos para fibra (FTTH) e inalámbrico (WISP).

## Qué significa cada estado

- **Del equipo:** nunca se envía al cliente.
- **Para el cliente:** se puede enviar desde la bandeja.
- **Falta completar datos de tu empresa:** el texto tiene marcadores entre corchetes («[Nombre del ISP]»). Mientras queden, la bandeja no deja enviarlo al cliente.
- **Inactivo:** deja de sugerirse y sus enlaces enviados dejan de abrir.

## Preguntas frecuentes

**Cargué los manuales de inicio, ¿ya los puedo mandar?**
Se crean «Del equipo». Completa los corchetes y después pásalos a «Para el cliente» desde **Editar**.

## Permisos necesarios

- Ver: `manuales.ver`. Crear, editar, activar y desactivar: `manuales.editar` (**Supervisor**).
