# Respuestas rápidas

## Para qué sirve

Guardar los textos que los agentes mandan muchas veces en la bandeja, para enviarlos con un toque o escribiendo su atajo.

## Cómo se usa

1. En **Administración**, abre **Respuestas rápidas**.
2. Pulsa **Nueva respuesta rápida**.
3. Escribe el **Atajo** (empieza con `/`, por ejemplo `/visita`) y el **Título** que se ve en el botón.
4. Escribe el texto. Usa `{{nombre}}` y se cambia por el nombre del cliente.
5. Si solo sirve para una cola, elígela. Si no, deja **Todas las colas**.
6. Revisa cómo se verá y pulsa **Crear respuesta**.

## Qué significa cada estado

- **Activa:** aparece en la bandeja.
- **Inactiva:** deja de aparecer. Puedes activarla de nuevo cuando quieras.

## Preguntas frecuentes

**¿Puedo usar negritas?**
No. Es texto plano: WhatsApp no muestra formato.
