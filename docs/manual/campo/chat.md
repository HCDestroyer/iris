# Chat en la app

## Para qué sirve

Hablar con despacho, tu cuadrilla y el equipo de cada orden. El cliente no lo ve.

## Cómo se usa

1. Toca **Chat** en la barra de abajo.
2. Abre una conversación o toca **Nuevo mensaje** para escribirle a alguien de tu empresa.
3. Escribe y envía. Puedes **Tomar foto** o **Compartir mi ubicación**.
4. Desde una orden, abre el **Chat de la orden** en **⋯ Más acciones**.

## Qué significa cada estado

- **Por enviar:** el mensaje espera señal.
- **No enviado:** no salió. Tócalo para reintentar o descartar.
- **Se eliminará al volver la señal.**

## Preguntas frecuentes

**¿Puedo borrar un mensaje?**
Sí, en los 15 minutos después de enviarlo.

**Sin señal no puedo abrir una conversación nueva.**
Para empezar una conversación hace falta señal. Las que ya tienes se leen igual.

## Permisos necesarios

- `chat.ver` y `chat.enviar` (rol **Técnico**).
