# Fotos

## Para qué sirve

Dejar fotos del trabajo como evidencia: la instalación, el equipo, la potencia, la caja…

## Cómo se usa

1. Abre el paso **Fotos**.
2. Toca **Agregar foto** y toma la foto.
3. Repite las que hagan falta.

## Qué significa cada estado

- **Foto guardada en el teléfono:** se sube sola en segundo plano.
- **Por subir:** espera señal para subir.
- **Esta orden ya no admite fotos:** la orden ya se cerró o se canceló.

## Preguntas frecuentes

**No tengo señal.**
Toma las fotos igual. Se suben cuando vuelva la señal, y el cierre espera a que suban.

## Permisos necesarios

- `adjuntos.subir` y `ordenes.registrar` (rol **Técnico**).
