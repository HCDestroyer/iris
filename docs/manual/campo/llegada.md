# Llegada

## Para qué sirve

Registrar que llegaste a la casa del cliente, con la hora y tu ubicación.

## Cómo se usa

1. Al llegar, abre el paso **Llegada**.
2. Toca **Llegué**.
3. Si el teléfono lo permite, Iris guarda tu ubicación.
4. Sigue con **Siguiente**.

## Qué significa cada estado

- **Llegada registrada con ubicación:** se guardó la hora y el lugar.
- **Llegada registrada sin ubicación:** se guardó la hora; el teléfono no dio ubicación.
- **Marca tu llegada para llenar este paso:** aún no tocas **Llegué**.

## Preguntas frecuentes

**No tengo GPS.**
La llegada se registra igual, sin ubicación.

## Permisos necesarios

- `ordenes.llegar` (rol **Técnico**).
