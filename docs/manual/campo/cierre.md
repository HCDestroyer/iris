# Firma del cliente y cierre

## Para qué sirve

Es el paso final. El cliente revisa lo que hiciste, firma, y la orden se cierra.

## Cómo se usa

1. Termina todo lo obligatorio. Si falta algo, Iris te dice qué es y te lleva ahí.
2. Abre **Firma del cliente y cierre**.
3. Muéstrale al cliente el **Resumen del trabajo**: checklist, fotos, materiales y equipos.
4. Escribe el **Nombre de quien firma** y, si hace falta, su **Documento (DPI)**.
5. Pide al cliente que firme en el recuadro.
6. Toca **Firmar y cerrar orden** (o **Cerrar orden** si la firma es opcional).

## Qué significa cada estado

- **Obligatoria para cerrar esta orden:** sin firma no se puede cerrar.
- **Opcional:** puedes cerrar sin firma.
- **Orden cerrada:** listo.
- **Las fotos o la firma aún se están subiendo:** el cierre se envía cuando terminen.
- **La orden está pausada:** reanúdala antes de cerrar.

## Preguntas frecuentes

**¿Puedo firmar antes?**
No. La firma solo aparece aquí, al final, junto con el cierre.

**Cerré sin señal.**
El cierre queda en el teléfono y se envía solo al volver la señal.
