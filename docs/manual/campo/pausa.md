# Pausar o marcar no realizada

## Para qué sirve

Detener una orden un rato (por ejemplo, esperando material) o avisar que no se pudo hacer.

## Cómo se usa

Para pausar:

1. En la orden, toca **Pausar**.
2. Elige el motivo: **Esperando material**, **El cliente no está**, **Mal clima**, **Sin acceso por ahora** u **Otro motivo** (con nota).
3. Confirma. La orden queda pausada y despacho ve el motivo.
4. Para seguir, toca **Reanudar**.

Si no se pudo hacer:

1. En la orden, toca **No se pudo**.
2. Elige el motivo y agrega el detalle.
3. Confirma. Despacho la reprogramará.

## Qué significa cada estado

- **Pausada:** en pausa no se registra trabajo; solo puedes agregar notas.
- **No realizada:** la orden no se hizo.

Motivos de no realizada: **El cliente no estaba**, **Sin acceso al lugar**, **Sin cobertura**, **Falta material**, **Equipo defectuoso**, **Mal clima**, **El cliente no aceptó** u **Otro motivo**.

## Preguntas frecuentes

**No me deja reanudar.**
Tu usuario no tiene permiso para reanudar: pídeselo a despacho.

## Permisos necesarios

- `ordenes.pausar`, `ordenes.reanudar` y `ordenes.fallar` (rol **Técnico**).
