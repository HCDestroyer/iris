# Integración entre frentes

Cada agente tiene su archivo `integration/<agente>.md` con lo que pide a otros frentes y lo que entrega. Nunca edites el de otro agente.

Los contratos compartidos viven en `contratos/`:

- `argosisp.md`: espejo de `argos-isp/.claude/integration/contratos/iris.md`.
- `horus.md`: espejo de `horus-flow/docs/integrations/iris.md`.
- `sync.md`: interno (API ↔ app de campo).
- `eventos.md`: payloads del catálogo de `CLAUDE.md`.
